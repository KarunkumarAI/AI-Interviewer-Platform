# Mandatory demo video checklist

1. Show the application and explain the React / FastAPI / PostgreSQL / Qdrant architecture.
2. Register and sign in.
3. Select AI/ML Engineer and upload an ML textbook PDF, tagged for that role.
4. Upload a candidate resume and show the extracted text/profile.
5. Start the interview and explain how the question is grounded in retrieved textbook chunks.
6. Submit a technical answer; show feedback, strengths, gaps and score.
7. Continue through five questions and show the final report.
8. Repeat with Backend Engineer and a backend-relevant textbook to demonstrate role-specific retrieval.
9. Briefly show the GitHub repository, README, environment configuration (with secrets hidden), and API docs.

Do not show API keys, passwords, personal candidate information, or copyrighted textbook pages in the public video.
